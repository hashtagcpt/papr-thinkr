Review a manuscript

    
Create a project pointing at your manuscript (.tex, .docx, .md, .txt or .pdf). Optionally add the
       reviewers' comments, and the analysis code and data behind the paper.

    
    
      
  • No reviewer comments? papr-thinkr reviews your first draft like a panel of harsh referees.
    • 
      
  • Have reviews? Every comment is triaged: is the reviewer right, how much work is it (with a
          confidence), and a drafted rebuttal when pushback is warranted, plus an independent critique of what they missed.
    • 
      
  • Results become a Word report, trackable items, proposed edits and a response letter.

LLM backends

    
Local models never send your manuscript anywhere. Cloud backends send the manuscript text (and any
      code/data summaries) to that provider. The CLI backends use your existing login for that tool and are run with
      tools disabled.

    

    
API keys

    
Only needed for the *-api backends and the Gemini CLI. Stored on this computer
      outside the repository; never shown again in full. See docs/api-keys-and-logins.md.
